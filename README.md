# Tori Kumanda

TORIMA hoparlör için kızılötesi (IR) kumanda uygulaması. İnternet, Bluetooth ve Wi-Fi gerektirmez; telefonun IR vericisini kullanır (Xiaomi 11T Pro'da var).

- Protokol: NEC, 38 kHz, varsayılan adres 0x00
- Tuş kodları uygulama içinden değiştirilebilir (⚙ Kodları düzenle)
- Bir tuş çalışmazsa 🔍 Kod tara ile doğru komutu bulup kaydet
